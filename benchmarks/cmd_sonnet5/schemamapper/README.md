# SchemaMapper dictionaries for the cMD benchmark

Copied unchanged from `MetaHarmonizerSchemaRegistry` (`schema/curatedmetagenomicdata/`,
commit `7c73848`; the cMD files were last changed in `ba2dfd4`), so a run does not depend on
the state of a registry checkout. `run_frozen.py` passes them to
`metaextract --column-mapper schemamapper`, and every ledger row records their SHA-256.

| File | Role |
|---|---|
| `cmd_target_attrs.csv` | target fields (`field_name,is_numeric_field`) |
| `cmd_target_attrs_alias_haiku.csv` | alias dictionary (generated by Claude Haiku 4.5; see `.meta.json`) |
| `cmd_target_attrs_allowed_values.json` | allowed values of enum fields (value matching) |

Note: the `.meta.json` records `prompt_version: cancer_genomics`, i.e. the aliases were
generated with the registry's cancer-genomics prompt rather than a microbiome-specific one.
